Lo que hiciste va en la dirección correcta.

## Qué pasó realmente

Tu problema no era “buscar dos veces”, sino esto:

* `BtnBuscarHM_Click` llama a `EjecutarBusquedaHM()`
* eso termina llamando a dos consultas seguidas:

  * `BuscarHMCabecera(...)`
  * `BuscarHMDetalle(...)`

Con tu versión anterior de `Connect()`, estabas reutilizando **la misma instancia** de `_connection`.

Entonces pasaba algo así:

1. Primera consulta obtiene `_connection`
2. la usa dentro de un `using (...)` o luego un `Disconnect()`
3. esa misma conexión compartida queda cerrada o disposed
4. la segunda consulta intenta reutilizar esa misma instancia
5. falla o entra en estados raros

## Conclusión

Para este tipo de app, **no te conviene compartir una sola conexión viva como campo global**:

```csharp
private AseConnection _connection;
```

Eso es frágil, especialmente si:

* haces varias consultas consecutivas
* usas `Task.Run(...)`
* disparas eventos
* varias funciones de `BDPrenda` llaman a `Connect()` internamente

`AseConnection` no deberías manejarla como recurso compartido de larga vida dentro de toda la clase.
Lo más sano es:

* **abrir conexión**
* **usar**
* **cerrar/liberar**
* **fin**

por cada operación.

# Qué opino de fondo

Tu bug revela que el diseño anterior tenía este problema:

## Diseño anterior

* conexión compartida
* varias funciones la usan
* una función la cierra
* otra la vuelve a usar
* choque

## Diseño nuevo

* cada método obtiene su propia conexión
* cada método la libera
* no hay interferencia

Eso es mucho más robusto.

# Entonces, ¿está mal crear una nueva conexión siempre?

No.
Para este caso, **está mejor**.

Además, normalmente los providers ADO.NET manejan internamente el pool de conexiones, así que abrir/cerrar por operación suele ser el patrón correcto desde la aplicación.

using System;
using System.Data;
using System.IO;
using Sybase.Data.AseClient;

namespace SampleApp_CSharp
{
    public class SybaseHelper
    {
        private string _serverName;
        private string _port;
        private string _database;
        private string _user;
        private string _password;

        public string LastError { get; private set; } = string.Empty;

        public AseConnection Connect()
        {
            try
            {
                LoadConfig();

                string connectionString =
                    $"Data Source={_serverName};Port={_port};Database={_database};Uid={_user};Pwd={_password};";

                var conn = new AseConnection(connectionString);
                conn.Open();
                return conn;
            }
            catch (Exception ex)
            {
                LastError = ex.Message;
                LogError("Error al conectar a Sybase", ex);
                throw;
            }
        }

        private void LoadConfig()
        {
            try
            {
                string basePath = AppDomain.CurrentDomain.BaseDirectory;
                string configPath = Path.Combine(basePath, "sybase.config");

                if (!File.Exists(configPath))
                    throw new FileNotFoundException("No se encontró el archivo sybase.config", configPath);

                foreach (var rawLine in File.ReadAllLines(configPath))
                {
                    string line = rawLine?.Trim();

                    if (string.IsNullOrWhiteSpace(line))
                        continue;

                    if (line.StartsWith("#") || line.StartsWith(";"))
                        continue;

                    int idx = line.IndexOf('=');
                    if (idx <= 0)
                        continue;

                    string key = line.Substring(0, idx).Trim().ToLowerInvariant();
                    string value = line.Substring(idx + 1).Trim();

                    switch (key)
                    {
                        case "server":
                        case "servername":
                        case "data source":
                            _serverName = value;
                            break;

                        case "port":
                            _port = value;
                            break;

                        case "database":
                        case "initial catalog":
                            _database = value;
                            break;

                        case "user":
                        case "uid":
                        case "username":
                            _user = value;
                            break;

                        case "password":
                        case "pwd":
                            _password = value;
                            break;
                    }
                }

                if (string.IsNullOrWhiteSpace(_serverName))
                    throw new Exception("Falta configurar 'server' en sybase.config.");

                if (string.IsNullOrWhiteSpace(_port))
                    throw new Exception("Falta configurar 'port' en sybase.config.");

                if (string.IsNullOrWhiteSpace(_database))
                    throw new Exception("Falta configurar 'database' en sybase.config.");

                if (string.IsNullOrWhiteSpace(_user))
                    throw new Exception("Falta configurar 'user' en sybase.config.");

                if (string.IsNullOrWhiteSpace(_password))
                    throw new Exception("Falta configurar 'password' en sybase.config.");
            }
            catch (Exception ex)
            {
                LastError = ex.Message;
                LogError("Error al cargar configuración Sybase", ex);
                throw;
            }
        }

        private void LogError(string mensaje, Exception ex)
        {
            try
            {
                string basePath = AppDomain.CurrentDomain.BaseDirectory;
                string logPath = Path.Combine(basePath, "sybase_error.log");

                File.AppendAllText(
                    logPath,
                    $"[{DateTime.Now:yyyy-MM-dd HH:mm:ss}] {mensaje}: {ex.Message}{Environment.NewLine}");
            }
            catch
            {
            }
        }
    }
}
