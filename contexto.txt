Ese error es claro:
Problema
DiscoverScanner.GetInstance() en tu proyecto no es sin parámetros.
Tu clase está definida para recibir:
C#
CCoreScannerClass m_pCoreScanner
Por eso falla esto:
C#
discoverScanner = DiscoverScanner.GetInstance();
y debe ser así:
C#
discoverScanner = DiscoverScanner.GetInstance(m_pCoreScanner);
Corrección exacta
En frmLector_Load, cambia esta línea:
C#
discoverScanner = DiscoverScanner.GetInstance();
por esta:
C#
discoverScanner = DiscoverScanner.GetInstance(m_pCoreScanner);
Orden correcto
Como discoverScanner depende de m_pCoreScanner, inicialízalo después de crear m_pCoreScanner:
C#
try
{
    m_pCoreScanner = new CCoreScannerClass();
    discoverScanner = DiscoverScanner.GetInstance(m_pCoreScanner);
}
catch (Exception ex)
{
    MessageBox.Show("Error inicializando CoreScanner: " + ex.Message);
}
Y scanToConnect lo dejas aparte:
C#
scanToConnect = ScanToConnect.GetInstance();
