Aquí está la función AdjustTabWidth lista para usar en WinForms:
C#
private void AdjustTabWidth()
{
    if (tabControl == null || tabControl.TabCount == 0)
        return;

    int totalWidth = tabControl.Width;

    // pequeño margen para que no se corte
    int ancho = totalWidth / tabControl.TabCount;

    if (ancho < 120)
        ancho = 120;

    tabControl.ItemSize = new Size(ancho, 40);
}

Si fuera tabControl1, entonces cambia la función así:

{
    if (tabControl1 == null || tabControl1.TabCount == 0)
        return;

    int ancho = totalWidth / tabControl1.TabCount;

    if (ancho < 120)
        ancho = 120;
