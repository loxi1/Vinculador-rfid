Perfecto. Ya que sí lee el RFID, el siguiente paso es mostrar cada lectura en dgvTagList, usando solo una columna RFID.
No necesitas TIP ni CANTIDAD por ahora.
Qué debes hacer
1. Deja dgvTagList con una sola columna
En el diseñador, o por código en frmLector_Load, configúralo así:
C#
private void ConfigurarGridRfid()
{
    dgvTagList.Columns.Clear();
    dgvTagList.Rows.Clear();

    dgvTagList.AllowUserToAddRows = false;
    dgvTagList.AllowUserToDeleteRows = false;
    dgvTagList.AllowUserToResizeRows = false;
    dgvTagList.MultiSelect = false;
    dgvTagList.ReadOnly = true;
    dgvTagList.RowHeadersVisible = false;
    dgvTagList.SelectionMode = DataGridViewSelectionMode.FullRowSelect;
    dgvTagList.AutoSizeColumnsMode = DataGridViewAutoSizeColumnsMode.Fill;

    dgvTagList.Columns.Add("RFID", "RFID");
}
Y en frmLector_Load llama:
C#
ConfigurarGridRfid();
2. Crear una lista para controlar duplicados
Si quieres validar cuando se repite un RFID, agrega esto en frmLector.cs:
C#
private readonly HashSet<string> _rfidLeidosGrid = new HashSet<string>(StringComparer.OrdinalIgnoreCase);
3. Mostrar cada RFID leído en el grid
Cambia tu método SetRfid por este:
C#
private void SetRfid(string rfid)
{
    if (InvokeRequired)
    {
        BeginInvoke(new Action<string>(SetRfid), rfid);
        return;
    }

    _ultimoRfid = (rfid ?? "").Trim().Replace(" ", "");

    if (string.IsNullOrWhiteSpace(_ultimoRfid))
        return;

    AgregarRfidAlGrid(_ultimoRfid);

    toolStripStatusLbl.Text = "RFID leído: " + _ultimoRfid;

    IntentarVincular();
}
4. Método para insertar en dgvTagList
Agrega este método:
C#
private void AgregarRfidAlGrid(string rfid)
{
    if (string.IsNullOrWhiteSpace(rfid))
        return;

    rfid = rfid.Trim().ToUpperInvariant();

    if (_rfidLeidosGrid.Contains(rfid))
    {
        toolStripStatusLbl.Text = "RFID repetido: " + rfid;
        return;
    }

    _rfidLeidosGrid.Add(rfid);

    dgvTagList.Rows.Insert(0, rfid);
}
Con eso:
el primer RFID aparece arriba
si lees otro diferente, también aparece
si repites uno, no lo duplica
