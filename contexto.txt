Sí. Hazla recibir el TabControl como parámetro.
C#
private void AdjustTabWidth(TabControl tabCtrl)
{
    if (tabCtrl == null || tabCtrl.TabCount == 0)
        return;

    int totalWidth = tabCtrl.Width;
    int tabCount = tabCtrl.TabCount;

    int tabWidth = totalWidth / tabCount;
    if (tabWidth < 100)
        tabWidth = 100;

    tabCtrl.ItemSize = new Size(tabWidth, 40);
}
Y la llamas así:
C#
AdjustTabWidth(this.tabControl);
Si quieres que también se recalcule cuando cambie el tamaño del formulario:
C#
private void frmLector_Resize(object sender, EventArgs e)
{
    AdjustTabWidth(this.tabControl);
}
Y en el Load:
C#
tabControl.DrawMode = TabDrawMode.OwnerDrawFixed;
tabControl.SizeMode = TabSizeMode.Fixed;
AdjustTabWidth(this.tabControl);
